РЕДАКТОР

Проект в одной карточке

Личный редактор NomadCatapult. Здесь сохраняется локальный черновик; клиентская ссылка обновится после публикации зашифрованного файла через ассистента.

Только ручная отметка для демонстрации условий этапа. Платёжных функций и проверки банком нет.

Задачи и согласования

Новая задача

Клиентская ссылка на сайте

Личный этап 1 · вымышленное демо. Скачайте клиентский JSON и передайте ассистенту для подготовки зашифрованного обновления. Файл на сайте заменяется под тем же ID; ключ остаётся только в приватной ссылке. Локальное сохранение ещё не означает публикацию.

Постоянную ссылку выдаёт локальный инструмент. Веб-редактор не имеет GitHub токенов и сам ничего не отправляет в репозиторий. Сейчас реальные клиентские данные не используем.

Опциональный незашифрованный снимок

Снимок не обновляется. После правок нужна новая ссылка. Этот старый hash-снимок не шифрует данные: получатель может их прочитать и изменить. Это не основной клиентский режим.

Открыть просмотр ↗

Localhost работает только на этом ПК. Предпросмотр по local-ID доступен только в этом браузере. Внешний зашифрованный просмотр требует публикации; на этом этапе она ещё не выполнена.

PNG содержит карточку с датой. JSON содержит только клиентские поля; внутренние заметки и неизвестные поля исключаются. Это незашифрованная локальная копия: храните её вне Git. Все суммы условные.

ПРЕДПРОСМОТР

Остаток ресурса — отдельно от готовности задач. Серый этап остаётся в плане и резерве; его детали раскрываются даже в ожидании. Все условия открывают старт, но не выполняют работу.
